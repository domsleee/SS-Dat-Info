# The TasSharedState wire contract. TAS_Helper's test_shared_layout.cpp
# (from the static_assert pins in shared_layout.hpp) and tas_shared's
# layout.rs (from its const-assert pins) each build this list from their own
# declarations and require it to match, so CI fails when the two disagree.
# Edit it only together with both sides and a TAS_SHARED_VERSION bump; a
# failing check prints that side's list.
#
#   struct <name> <size> <align>
#   field <struct>.<field> <wire type> <offset> <size> <align>
#   const <name> <value>
#
# Wire types: u8 / u32 / f32 (C++ char, volatile and Rust AtomicU32 are wire
# u8 / u32), arrays as [element;count], nested structs by name.
